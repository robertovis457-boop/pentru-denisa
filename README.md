
# Site pentru Denisa

Am pregătit proiectul ca să îl poți publica ușor pe Vercel.

## Pași simpli

1. Descarcă acest folder sau arhiva zip.
2. Pune-l într-un repo nou pe GitHub.
3. Intră pe Vercel și conectează contul tău GitHub.
4. Apasă **New Project**.
5. Alege repo-ul cu acest proiect.
6. Apasă **Deploy**.
7. După publicare, primești un link pe care îl poți trimite imediat.

## Dacă vrei să îl testezi pe calculatorul tău

```bash
npm install
npm run dev
```

Apoi deschizi în browser:

```bash
http://localhost:3000
```

## Fișiere importante

- `app/page.tsx` – pagina principală și toate secțiunile
- `app/globals.css` – stilurile
- `public/images/` – pozele voastre
